# Research artifacts

This directory is for normalized, provenance-preserving UPPETITE place research.

Generated/maintained artifacts:

- `observations.jsonl` — source observations
- `claims.jsonl` — structured factual claims
- `candidates.jsonl` — possible new places
- `decisions.jsonl` — human moderation decisions
- `runs/` — per-run metadata

Do not store login cookies, access tokens, full social posts, complete menus, full transcripts, or raw private-group exports here.

See `docs/place-research-system.md` and `docs/source-policy.md`.
