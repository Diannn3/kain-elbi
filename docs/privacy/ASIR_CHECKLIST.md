# Annual Security Incident Report (ASIR) Checklist

- Reporting channel: NPC Data Breach Notification Management System (DBNMS).
- Maintain the incident register throughout the year.
- Count/classify mandatory notifications, voluntary notifications, and other security incidents.
- Reconcile the register before submission.
- Submit the previous calendar year's ASIR within the NPC's current filing window.
- Keep submission evidence/reference outside the public repo if it contains account-specific information.

Reference:
https://privacy.gov.ph/pips-and-pics/breach-reporting/
