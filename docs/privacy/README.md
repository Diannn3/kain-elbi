# UPPETITE Privacy Compliance Pack

This folder operationalizes the project's Philippine privacy/compliance work. It is not a substitute for advice from a Philippine privacy professional.

Before broad public beta:
1. Confirm the legal Personal Information Controller (PIC).
2. Designate/confirm the privacy contact or Data Protection Officer (DPO), as applicable.
3. Complete the NPC registration-vs-exemption assessment and file through NPCRS when required.
4. Complete/review the PIA.
5. Configure a dedicated privacy contact email if possible.
6. Configure the daily `photo-maintenance` job and `UPPETITE_MAINTENANCE_SECRET`.
7. Review all Google Forms so they request only needed fields and include Contributor Terms/privacy notices at collection.

Primary official references:
- Data Privacy Act / IRR: https://privacy.gov.ph/data-privacy-act/
- NPC registration/exemption: https://privacy.gov.ph/pips-and-pics/exemption/
- NPC breach/ASIR reporting: https://privacy.gov.ph/pips-and-pics/breach-reporting/

- IPOPHL photography/copyright FAQ: https://www.ipophil.gov.ph/news/ipophl-answers-faqs-on-photography-and-copyright/
