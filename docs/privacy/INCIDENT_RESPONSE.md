# Security Incident / Personal Data Breach Response

## Roles
- Incident lead: __________________
- Privacy contact / DPO: __________________
- Supabase owner: __________________
- Deployment owner: __________________

## Immediate steps
1. Contain the incident without destroying evidence.
2. Preserve relevant logs/configuration with minimum necessary personal data.
3. Identify systems/data/categories/time window affected.
4. Rotate exposed secrets and revoke compromised access.
5. Determine whether personal data was accessed, altered, lost, disclosed, or made unavailable.
6. Record the incident in the incident register.

## NPC assessment
Assess mandatory notification promptly. Where mandatory notification requirements are met, prepare the NPC/data-subject notification process so the applicable 72-hour period can be met.

Use DBNMS for NPC breach notifications and ASIR submissions:
https://privacy.gov.ph/pips-and-pics/breach-reporting/

## Post-incident
- Root-cause analysis.
- Corrective controls.
- User remediation where appropriate.
- Update PIA/security policy.
- Include incidents in the applicable ASIR classification, including incidents not subject to immediate mandatory notification.
