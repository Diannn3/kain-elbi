# Data Subject Request Procedure

Public entry point: `/privacy-request`

1. Record the request date and requested right/action.
2. Ask only for information necessary to locate the relevant record.
3. Do not ask for government ID by default.
4. Verify control/connection proportionately to the record involved.
5. Search relevant systems (community DB, photo moderation records, external form records where applicable).
6. Correct/delete/restrict records when appropriate and legally permitted.
7. Document the outcome and response date.
8. If the request cannot be completed, document the reason and provide the privacy contact.

Because UPPETITE avoids accounts, the process should not create a larger identity dataset merely to process a privacy request.
